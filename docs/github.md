# Repositorio GitHub

## Control de Versiones

Durante el desarrollo del proyecto se utilizó GitHub como plataforma de control de versiones y colaboración.

Esta herramienta permitió almacenar el código fuente, registrar cambios realizados por los integrantes del equipo y mantener un historial organizado del desarrollo del proyecto.

---

## Repositorio del Proyecto

El repositorio contiene todos los archivos necesarios para la construcción y funcionamiento de la aplicación web MAMBAQ Interactivo.
