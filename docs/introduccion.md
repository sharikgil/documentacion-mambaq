# Introducción

MAMBAQ Interactivo es una plataforma web desarrollada como proyecto académico para la asignatura Tecnologías Web.

El proyecto está inspirado en el Museo de Arte Moderno de Barranquilla (MAMBAQ) y busca combinar arte, cultura y tecnología mediante herramientas de Inteligencia Artificial.

![Inicio](/img/inicio.png)

La plataforma ofrece información sobre el museo, una galería visual y un museo interactivo donde los usuarios pueden cargar sus propias obras digitales.
