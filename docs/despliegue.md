# Despliegue del Proyecto

## Publicación de la Aplicación

Una vez finalizado el desarrollo de MAMBAQ Interactivo, se procedió a publicar la aplicación en internet para que pudiera ser accesible desde cualquier dispositivo con conexión a la red.

Para ello se utilizaron servicios de hosting y administración de dominios que permitieron desplegar la plataforma de forma profesional.

---

## Adquisición del Dominio

Se adquirió un dominio personalizado para facilitar el acceso al proyecto y mejorar su presentación.

Dominio utilizado:

**mambaqinteractivo.xyz**

La compra y administración del dominio se realizó mediante Namecheap.

![Dominio Namecheap](/img/dominio.png)

---

## Configuración DNS

Posteriormente se configuraron los registros DNS necesarios para conectar el dominio adquirido con la plataforma de alojamiento seleccionada.

Este proceso permitió que las solicitudes realizadas al dominio fueran dirigidas correctamente al servidor donde se encuentra alojada la aplicación.

---

## Hosting de la Aplicación

Para el despliegue de la documentación y de la aplicación web se utilizó Netlify.

Netlify permitió:

- Publicación rápida del proyecto.
- Actualización sencilla del contenido.
- Certificado HTTPS automático.
- Integración con GitHub.
- Disponibilidad global del sitio.

![Netlify](/img/netlify.png)

---

## Resultado Final

Después de completar la configuración del dominio y del hosting, el proyecto quedó disponible públicamente a través de internet.

Esto permitió que cualquier usuario pudiera acceder al sitio web sin necesidad de instalar software adicional.
