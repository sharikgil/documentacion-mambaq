# Conclusiones

El desarrollo de MAMBAQ Interactivo permitió aplicar los conocimientos adquiridos durante la asignatura de Tecnologías Web en un proyecto real que integra diseño web, programación, despliegue e Inteligencia Artificial.

La utilización de Teachable Machine y TensorFlow.js hizo posible implementar un sistema capaz de clasificar imágenes de manera automática, agregando una funcionalidad innovadora a la plataforma.

Además, el uso de GitHub facilitó el trabajo colaborativo entre los integrantes del equipo, mientras que Netlify y Namecheap permitieron publicar el proyecto en internet mediante un dominio personalizado.

El proyecto demostró cómo las tecnologías web pueden combinarse con herramientas de Inteligencia Artificial para crear experiencias educativas e interactivas orientadas a diferentes públicos.

Finalmente, MAMBAQ Interactivo logró cumplir los objetivos planteados, ofreciendo una plataforma que promueve la cultura, el arte y la participación de los usuarios mediante el uso de tecnologías modernas.
